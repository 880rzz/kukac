Wie spielst du?

Ziel: Sammle so viele Punkte wie möglich, ohne gegen Wände, Hindernisse oder dich selbst zu stoßen.

Punkte: Stern +10, seltene Goldmünze +25. Schnelles Sammeln baut einen Combo-Bonus auf.

Levels: Alle 80 Punkte beginnt ein neues Level. Tempo und Hindernisse nehmen zu.

Boost: Shift oder BOOST auf Mobilgeräten. Schneller, aber riskanter.

Steuerung: Pfeile/WASD, D-Pad oder Wischen. Leertaste: Pause, R: Neustart, M: Ton.

Eindringlinge: Soldaten, Drachen und Retro-Helden laufen aufs Feld, stehlen Sterne und können den Wurm treffen.

Rekord: Der Browser speichert deinen Bestwert lokal.

Your data in KUKAC 3D

This page explains in simple language what happens to your data.

What is stored?

Your nickname, a protected password hash, profile creation time and game statistics such as high score, levels, games, stars, coins and achievements.

Where is it stored?

The Arcade ID and game statistics are stored locally in this browser on this device. They are not written into the public GitHub repository and KUKAC has no central player-profile database.

What about my password?

Your readable password is not stored. The browser stores a salted PBKDF2-SHA-256 hash. Do not reuse an important password from school, email or another account.

What happens when I open the game?

The game is delivered through GitHub Pages. The hosting provider may process technical connection data such as an IP address and request information when the page is loaded.

Is my profile public?

There is no central public KUKAC profile or worldwide leaderboard. The local leaderboard only contains profiles saved in this browser. On a shared device, other people using the same browser profile may see those local nicknames and game statistics.

What should I use as a nickname?

Use a fantasy name. Do not put your full real name, address, phone number, email address or other private information in your nickname.

How can I delete my data?

You can delete your local Arcade ID from this browser. Clearing this site's browser storage also removes local KUKAC profiles and scores. Export a recovery backup first if you want to keep a profile.

The checkbox confirms that you have read this information. It is not permission for advertising or tracking.
